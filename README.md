
# Matplotlib Practice Dashboard

This project is a practice-based data visualization dashboard created using Python and Matplotlib. The main purpose of this project is to understand and apply basic data visualization techniques using a student performance dataset.

The dataset contains information such as Day, Study Hours, Marks, Sleep Hours, Screen Time, Water Intake, and Assignment ID. Different types of charts were created to analyze and visualize the data in a simple and meaningful way.

## Visualizations Included

* Line Plot: Used to visualize the relationship between Day and Marks.
* Bar Chart: Used to compare Study Hours across different days.
* Scatter Plot: Used to analyze the relationship between Study Hours and Marks.
* Pie Chart: Used to visualize the average values of Study Hours, Sleep Hours, Screen Time, and Water Intake.
* Dashboard: Combined multiple visualizations into a 2×2 layout for easy comparison.

## Key Analysis

The project also includes basic statistical analysis such as calculating average Study Hours and finding the correlation between Study Hours and Marks.

The scatter plot was used to understand whether increased study hours are associated with higher marks. The correlation value was calculated using Pandas to support the observation.
